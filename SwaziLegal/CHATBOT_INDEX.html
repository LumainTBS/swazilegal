🔌 WordPress Plugin Installation

Step 1: Install Plugin

  1. Copy swazilegal-chatbot folder to wp-content/plugins/
  2. Go to WordPress Admin → Plugins
  3. Find "SwaziLegal Chatbot" and click "Activate"

Step 2: Configure Settings

  1. Go to Admin → Chatbot → Settings
  2. Choose your chatbot type (Drift, Botpress, Intercom, or Custom)
  3. Enter API credentials if using third-party service
  4. Check "Enable Chatbot"
  5. Click "Save Changes"

Step 3: Done!

Your chatbot now appears on all pages. Visit your website to see it in action!
