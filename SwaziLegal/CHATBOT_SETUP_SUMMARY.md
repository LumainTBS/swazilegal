## 🚀 Getting Started (Choose One)

### Option A: WordPress Plugin (Easiest)
```
1. Copy swazilegal-chatbot folder to /wp-content/plugins/
2. Activate plugin in WordPress Admin
3. Go to Chatbot → Settings
4. Choose chatbot type and enter API ID
5. Enable and save
✅ Done!
```

### Option B: Manual Code (More Control)
```
1. Choose your chatbot service (Drift, Botpress, Intercom)
2. Get your API ID
3. Add script to wp-content/themes/swazilegal-theme/header.php
4. Place before </head> tag
✅ Done!
```

### Option C: Custom Chatbot (No Third Party)
```
1. Use the HTML from chatbot-integration.html
2. Extract the custom chatbot code
3. Customize FAQ data in js/chatbot.js
4. Add to your website
✅ Done!
```
