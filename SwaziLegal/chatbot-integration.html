🔧 Implementation Examples

1. Drift Chatbot (Easiest - Recommended for Most)

Add this single script to your website header. No other configuration needed.

<!-- Add to <head> section --> <script> !function() { var t = window.driftt = window.drift = window.drift || [], e = !1; if (!t.identify) return void (t.addLoad = function(n) { var a = document.createElement("script"); a.async = !0, a.src = n, document.head.appendChild(a); }); t.load("YOUR_DRIFT_ID"); }(); </script>

Steps:
1. Sign up at drift.com (free tier)
2. Get your Drift ID from dashboard
3. Replace YOUR_DRIFT_ID with your actual ID
4. Paste script into <head> of every page
5. Configure bot responses in Drift dashboard

2. Botpress Cloud Chatbot (Easy - More Control)

Botpress provides a pre-built widget for quick integration.

<script src="https://cdn.botpress.cloud/webchat/v1/inject.js"></script> <script> window.botpressWebChat.init({ botId: "YOUR_BOT_ID", hostUrl: "https://cdn.botpress.cloud/webchat", messagingUrl: "https://messaging.botpress.cloud", clientId: "YOUR_CLIENT_ID" }); </script>

Steps:
1. Sign up at botpress.com
2. Create new bot in dashboard
3. Get Bot ID and Client ID
4. Add script to website
5. Train bot with FAQ content

3. Custom Chatbot Widget (Full Control)

Build your own chatbot using HTML, CSS, and JavaScript.

<!-- Add to your HTML body --> <div id="chatbot-widget" class="chatbot-container"> <div class="chatbot-header"> <h3>💬 SwaziLegal Assistant</h3> <button id="close-chatbot">×</button> </div> <div id="chatbot-messages" class="chatbot-messages"></div> <div class="chatbot-input"> <input type="text" id="user-message" placeholder="Ask about our services..."> <button id="send-btn">Send</button> </div> </div>

Add JavaScript Logic:

// FAQ Knowledge Base const faqData = { "practice areas": "We offer services in Corporate Law, Family Law, Criminal Defense, and more.", "consultation": "Schedule a free consultation at https://swazilegal.sz/contact", "contact": "Call: +268 76 805 805 | WhatsApp: +268 78132527", "team": "Our team includes experienced attorneys across multiple practice areas.", "services": "Visit our services page to learn about all available legal services." }; // Simple matching function function findAnswer(question) { const lower = question.toLowerCase(); for (let [key, answer] of Object.entries(faqData)) { if (lower.includes(key)) return answer; } return "I didn't understand that. Try asking about: practice areas, consultation, contact, team, or services."; } // Send message handler document.getElementById("send-btn").addEventListener("click", () => { const message = document.getElementById("user-message").value; if (!message.trim()) return; // Add user message addMessage(message, "user"); // Get bot response const answer = findAnswer(message); setTimeout(() => addMessage(answer, "bot"), 500); document.getElementById("user-message").value = ""; }); // Add message to chat function addMessage(text, sender) { const container = document.getElementById("chatbot-messages"); const msgDiv = document.createElement("div"); msgDiv.className = `message ${sender}`; msgDiv.innerHTML = `<p>${text}</p>`; container.appendChild(msgDiv); container.scrollTop = container.scrollHeight; }

Add Styling:

.chatbot-container { position: fixed; bottom: 20px; right: 20px; width: 400px; max-height: 600px; background: white; border-radius: 12px; box-shadow: 0 10px 40px rgba(0, 0, 0, 0.2); display: flex; flex-direction: column; z-index: 9999; font-family: 'Segoe UI', sans-serif; } .chatbot-header { background: linear-gradient(135deg, #0d47a1, #1565c0); color: white; padding: 1rem; border-radius: 12px 12px 0 0; display: flex; justify-content: space-between; align-items: center; } .chatbot-messages { flex: 1; overflow-y: auto; padding: 1rem; background: #f9f9f9; } .message { margin-bottom: 1rem; display: flex; } .message.user { justify-content: flex-end; } .message.user p { background: #0d47a1; color: white; padding: 0.8rem; border-radius: 12px; max-width: 70%; } .message.bot p { background: #e0e0e0; color: #333; padding: 0.8rem; border-radius: 12px; max-width: 70%; } .chatbot-input { display: flex; gap: 0.5rem; padding: 1rem; border-top: 1px solid #e0e0e0; } .chatbot-input input { flex: 1; padding: 0.8rem; border: 1px solid #ddd; border-radius: 8px; font-size: 1rem; } .chatbot-input button { padding: 0.8rem 1.5rem; background: #0d47a1; color: white; border: none; border-radius: 8px; cursor: pointer; font-weight: 600; } .chatbot-input button:hover { background: #1565c0; } @media (max-width: 600px) { .chatbot-container { width: 100%; max-width: calc(100% - 20px); bottom: 10px; right: 10px; } }

Method 1: Add to Theme Footer (functions.php)

// Add to wp-content/themes/swazilegal-theme/functions.php add_action('wp_footer', 'add_chatbot_script'); function add_chatbot_script() { ?> <script> !function() { var t = window.driftt = window.drift || [], e = !1; if (!t.identify) return void (t.addLoad = function(n) { var a = document.createElement("script"); a.async = !0, a.src = n, document.head.appendChild(a); }); t.load("YOUR_DRIFT_ID"); }(); </script>
