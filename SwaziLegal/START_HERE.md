# 🤖 SwaziLegal Chatbot Integration - START HERE

Welcome! You have a complete, production-ready chatbot solution for your SwaziLegal website.

## ⚡ Quick Start (5 Minutes)

### For WordPress Sites (Recommended)

1. **Copy the plugin folder:**
   - Move `swazilegal-chatbot` to `wp-content/plugins/`

2. **Activate in WordPress:**
   - Admin → Plugins
   - Find "SwaziLegal Chatbot"
   - Click "Activate"

3. **Configure:**
   - Admin → Chatbot → Settings
   - Choose chatbot type (Drift recommended)
   - If using Drift: Get API ID from [drift.com](https://drift.com), paste it
   - Check "Enable Chatbot"
   - Click "Save Changes"

4. **Done!** Your chatbot appears on all pages ✅

## 🚀 Recommended Setup (Drift + WordPress Plugin)

### Step 1: Sign Up for Free Drift Account
1. Go to [drift.com](https://drift.com)
2. Click "Start for Free"
3. Create account with your business email
4. Get your **Drift ID** from dashboard
5. Copy it (you'll need it in Step 3)

### Step 2: Install WordPress Plugin
1. Copy `swazilegal-chatbot` folder to `wp-content/plugins/`
2. Admin → Plugins → Activate "SwaziLegal Chatbot"

### Step 3: Configure Plugin
1. Admin → Chatbot → Settings
2. Select "Drift" as chatbot type
3. Paste your Drift ID
4. Check "Enable Chatbot"
5. Click "Save Changes"

### Step 4: Test
1. Visit your website
2. Look for chatbot in bottom-right corner
3. Try asking a question
4. Should get relevant response!
